## BookMyStay - Hotel Stay Management System

Simulates **Hotel Room Booking & Stay Management System** using Java to build a hotel booking platform. Starting from a simple welcome page, the project gradually introduces room management, booking workflows, inventory tracking, reporting, concurrency and persistent storage.

### Features Included -

| Branch | Description |
|---------|-------------|
| UC1-Welcome_Page | Display application welcome screen |
| UC2-Room_Management | Implement room hierarchy using OOP |
| UC3-Room_Inventory | Manage room availability |
| UC4-Room_Search | Search available rooms |
| UC5-Booking_Queue | Queue booking requests |
| UC6-Room_Allocation | Allocate rooms and update inventory |
| UC7-Add_On_Services | Manage additional hotel services |
| UC8-Booking_History | Generate booking history and reports |
| UC9-Booking_Validation | Validate bookings using custom exceptions |
| UC10-Booking_Cancellation | Cancel bookings and restore inventory |
| UC11-Concurrent_Booking | Process bookings using multithreading |
| UC12-Persistence | Save and restore application state |

### Project Setup Guide -

1. Clone Repository: ```bash git clone https://github.com/yourusername/book-my-stay.git```
2. Navigate to Project: ```bash cd book-my-stay```
3. Run the application: Compile & run the Java application using your preferred IDE (IntelliJ IDEA, Eclipse, or VS Code) or the Java command line tools.
